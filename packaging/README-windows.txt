AI 쇼핑 쇼츠 자동화 - Windows 실행 방법
========================================

1. 이 폴더(AI-Shorts)를 원하는 곳에 통째로 두세요.
   (바탕화면, 문서 등. 압축을 푼 상태여야 합니다)

2. AI-Shorts.exe를 더블클릭하세요.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
     (서명하지 않은 프로그램이라 처음 한 번 나옵니다)
   - 방화벽 허용 창이 뜨면 [허용]을 누르세요. 이 PC 안에서만 씁니다.

3. 처음 실행하면 브라우저에 [설정 점검] 화면이 열립니다.
   - https://aistudio.google.com/apikey 에서 Gemini 키(무료)를 받아
     '키 넣기'의 Gemini 칸에 붙여 넣고 [저장하기]를 누르세요.
   - 저장하면 프로그램이 저절로 다시 켜지며 바로 적용됩니다.
   - 아이템 찾기·무료 스톡 영상·유튜브 올리기용 키도 같은 곳에 넣으면 됩니다.

4. 같은 화면의 [점검 시작]으로 키가 제대로 동작하는지 확인하세요.

- 검은 창(콘솔)을 닫으면 프로그램이 종료됩니다.
- 이미 켜져 있을 때 다시 실행하면 브라우저만 열립니다.
- 만든 영상과 설정은 이 폴더의 data, output 폴더와 .env에 저장됩니다.
  새 버전으로 바꿀 때는 이 세 가지를 새 폴더로 옮기면 그대로 이어서 쓸 수 있습니다.
- 키를 바꿀 때도 [설정 점검] 화면에서 넣고 저장하면 됩니다.

포함된 FFmpeg(ffmpeg 폴더)는 GPL 라이선스입니다 (https://ffmpeg.org).
