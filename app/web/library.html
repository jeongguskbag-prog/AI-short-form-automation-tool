    설명란

    유튜브에 올리기

    유튜브에 올리려면 본인 Google Cloud 프로젝트의 OAuth 클라이언트가 필요해요 (한 번만).
    1. YouTube Data API v3를 사용 설정합니다.
    2. OAuth 동의 화면을 '외부'로 만들고, 테스트 사용자에 본인 구글 계정을 넣습니다.
    3. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션을 만들고, 승인된 리디렉션 URI에 를 넣습니다.
    4. 서버 .env에 YOUTUBE_OAUTH_CLIENT_ID, YOUTUBE_OAUTH_CLIENT_SECRET을 넣고 다시 켭니다.

    구글 앱 심사 전에는 무엇을 골라도 비공개로 올라가요. 유튜브 스튜디오에서 공개로 바꾸세요. 설명란(광고 표시 포함)과 해시태그, 'AI 사용' 표시가 함께 들어가요. 업로드는 하루 약 6건까지예요.
