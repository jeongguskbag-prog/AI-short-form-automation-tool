아이템 찾기

API 키

이 서버는 API 키가 있어야 쓸 수 있습니다. 키는 이 브라우저에만 저장됩니다.

상품명·해시태그·작성자·공개 댓글에서 찾습니다. 즐겨찾기는 검색 조건과 관계없이 맨 앞에 표시합니다. 성과는 조회수 ÷ 채널 구독자 수입니다 (x412 = 구독자의 412배가 봄).

YouTube API 키를 넣어 주세요

인기 쇼츠를 모으려면 무료 YouTube Data API 키가 필요합니다.
  1. Google Cloud 콘솔에서 프로젝트를 만들고 YouTube Data API v3를 사용 설정합니다.
  2. 사용자 인증 정보 → API 키 만들기로 키를 받습니다.
  3. 서버의 .env에 YOUTUBE_API_KEY=받은키를 넣고 서버를 다시 시작합니다.
